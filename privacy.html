プライバシーポリシー

YouTube Analytics V2 における Google ユーザーデータの取り扱いについて定めます。

1. 取得する情報

本ツールは Google OAuth を通じて、運営者本人が管理する YouTube チャンネルについて、YouTube アカウント情報、チャンネル・動画情報、および YouTube Analytics の閲覧データにアクセスします。

2. 利用目的

取得した情報は、動画の再生数、視聴時間、視聴維持率、流入元、デバイス別傾向その他のパフォーマンス指標を集計・分析し、運営者本人の YouTube チャンネル運営を改善する目的にのみ利用します。

3. 保存

取得したデータは、運営者本人が管理する Google スプレッドシート、Google Apps Script その他の運営者管理下の環境に保存される場合があります。保存期間は分析上必要な範囲とし、不要となったデータは削除します。

4. 第三者提供・販売

Google ユーザーデータを販売しません。また、法令に基づく場合または本ツールの動作に必要なサービス連携を除き、第三者へ提供しません。

5. Google API Services User Data Policy

本ツールによる Google API から取得した情報の利用は、Google API Services User Data Policy を含む Google の適用ポリシーに従います。取得したデータは、本ポリシーに記載した目的の範囲内でのみ利用します。

6. アクセス権の取り消し

利用者は Google アカウントのセキュリティ設定から、本ツールに付与したアクセス権を取り消すことができます。アクセス権を取り消した場合、それ以降の新規データ取得は行われません。

7. 改定

本ポリシーは、機能変更や法令・Google ポリシーの変更等に応じて更新することがあります。最新版は本ページで公開します。
